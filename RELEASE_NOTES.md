Mouse Rate 1.0.1 fixes the Input Monitoring loop.

**Fixed:** If you had an earlier copy, System Settings kept showing Mouse Rate as allowed under Input Monitoring, but the app still asked for permission, even after reinstalling. Mouse Rate now clears its own old entry and asks once. Turn the switch on and you're done.

**Fixed:** If another mouse app was holding one of your mouse's connections, Mouse Rate showed the permission screen even with access on. It now counts every mouse it can open.

**Easier:** Mouse Rate asks for Input Monitoring as soon as it opens, and reopens itself once you turn it on.

**Install:** open the DMG and drag Mouse Rate into Applications. The first time you open it, macOS says it can't verify the app because it isn't signed with a paid Apple certificate yet. Go to System Settings > Privacy & Security, scroll down and click Open Anyway. When Mouse Rate asks for Input Monitoring, click Open System Settings, turn on Mouse Rate, then click Quit & Reopen.

No network code. Nothing is saved or sent. Built from this exact tag by GitHub Actions. The SHA-256 checksum is attached.
