Mouse Rate 1.0.2 links to the Almost Perfect Mac mouse video.

**New:** Copy and paste in the YouTube comments now opens the mouse video (https://youtu.be/xiBbThhUgvY), so you can paste your result right under it. Before, it opened the channel page.

**New:** the bottom of the report has a Watch the video card that opens the ultimate mouse guide for Mac.

**Also in this version (from 1.0.1):** if System Settings showed Mouse Rate as allowed under Input Monitoring but the app still asked, Mouse Rate now clears its own old entry and asks once. It also counts every mouse it can open, even when another mouse app holds one connection, and it reopens itself once you turn the switch on.

**Updating from an earlier copy:** macOS treats each new version as a new app, so it asks for Input Monitoring one more time. Turn the switch on, then click Quit & Reopen.

**Install:** open the DMG and drag Mouse Rate into Applications. The first time you open it, macOS says it can't verify the app because it isn't signed with a paid Apple certificate yet. Go to System Settings > Privacy & Security, scroll down and click Open Anyway. When Mouse Rate asks for Input Monitoring, click Open System Settings, turn on Mouse Rate, then click Quit & Reopen.

No network code. Nothing is saved or sent. Built from this exact tag by GitHub Actions. The SHA-256 checksum is attached.
